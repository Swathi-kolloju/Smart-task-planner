# Smart Task Planner

A modern full-stack MERN application designed for daily task planning, tracking, and productivity management.

## Tech Stack

- Frontend: React, Vite, CSS
- Backend: Node.js, Express.js
- Database: MongoDB Atlas (Mongoose)

## Features

- Create, update, and delete daily tasks
- Task tracking dashboard
- Responsive UI
- RESTful API architecture

## Getting Started Locally

### Prerequisites
- Node.js installed
- MongoDB Atlas account and connection string

### 1. Clone the repository
git clone https://github.com/Swathi-kolloju/Smart-task-planner.git
cd Smart-task-planner

### 2. Backend Setup
cd backend
npm install
node server.js

### 3. Frontend Setup
cd frontend
npm install
npm run dev
